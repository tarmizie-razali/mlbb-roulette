Using your own hero art
Every portrait is a placeholder right now — it falls back to a colored initial badge because no image file was found. To swap in real art, create a folder named images next to this HTML file, and drop in a photo for each hero named exactly like images/hero-slug.jpg (e.g. images/hayabusa.jpg, images/yi-sun-shin.jpg). The page will automatically pick it up — no code changes needed. JPG or PNG both work.
